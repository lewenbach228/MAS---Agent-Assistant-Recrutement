# Delivery Plan Template

Ce fichier sert a piloter l'execution du projet par phases.

## Phase 1 - Cadrage

Etat :

Livrables :

- kickoff rempli
- probleme fige
- demo principale choisie
- hors-scope defini

## Phase 2 - Structure

Etat :

Livrables :

- structure repo propre
- README initial
- stack validee
- plan technique V1

## Phase 3 - Flux principal

Etat :

Livrables :

- flux principal fonctionnel
- scenario de demo stable
- premiere preuve visible

## Phase 4 - Preuves

Etat :

Livrables :

- captures
- schema
- before / after si pertinent
- notes de demo

## Phase 5 - Publication

Etat :

Livrables :

- repo propre
- build OK
- deploy OK
- liens publics

## Phase 6 - Contenu

Etat :

Livrables :

- angles de posts
- script video
- actifs reutilisables

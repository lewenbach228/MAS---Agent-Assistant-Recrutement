# Content Angles

## Angle maitre

`IA Recruter` n'est pas un projet RH de plus. C'est un portfolio qui sert a prouver une competence d'architecte de systemes multi-agents IA sur un cas metier simple a comprendre.

Positionnement honnete :

- c'est un `pipeline multi-agent local`
- c'est une `demo agentique hybride`
- ce n'est pas encore un `veritable systeme agentique distribue`

## Les 6 competences a marteler

1. `Architecture multi-agent`
   - agents nommes
   - responsabilites claires
   - moteur d'execution separe
2. `Arbitrage LLM vs deterministe`
   - modes `deterministic`, `live_llm`, `compare`
   - fallback explicite
3. `Supervision humaine`
   - review gate
   - zero automatisation finale
4. `Explicabilite`
   - artefacts inspectables
   - comparison artifact
5. `Qualite d'implementation`
   - types
   - tests
   - couche provider dediee
6. `Pensee produit`
   - demo stable
   - UX lisible
   - preuve visuelle rapide

## Angles de posts

1. "Pourquoi j'ai construit un vrai moteur de run au lieu de laisser le hook React tout faire."
2. "Comment prouver une competence agent IA sans tomber dans la demo full LLM fragile."
3. "Deterministic, live, compare : la bonne facon de montrer un arbitrage IA credible."
4. "Pourquoi chaque agent devrait produire un artefact visible dans une demo portfolio."
5. "Le fallback n'est pas un detail technique : c'est une preuve d'architecture."
6. "Comment garder l'humain dans la boucle dans un systeme RH assiste par IA."
7. "Ce que mon projet RH ne cherche volontairement pas a prouver."
8. "Pourquoi je refuse d'appeler mon projet 'distribue' tant que l'architecture ne l'est pas reellement."

## Phrases fortes reutilisables

- "Je ne voulais pas une UI qui simule des agents, je voulais un systeme qui expose ses sorties intermediaires."
- "Le projet prouve autant ma capacite de fallback et de gouvernance que ma capacite a brancher un provider."
- "Le mode compare est la piece la plus importante pour montrer un jugement d'architecte."
- "La revue humaine n'est pas un ajout cosmetique, c'est une contrainte structurelle du systeme."
- "Je prefere decrire honnetement une demo agentique hybride plutot que survendre un faux systeme distribue."
- "Le niveau senior ne se voit pas dans les buzzwords, il se voit dans les tradeoffs, les fallbacks et les limites assumees."

## Ce qu'il ne faut pas raconter

- que le projet automatise le recrutement
- que le scoring est une verite RH
- que le live mode couvre deja tout le pipeline
- qu'il s'agit d'un produit enterprise fini
- qu'il s'agit deja d'un systeme agentique distribue
- que les agents sont deployes comme services separes

## Storyline recommandee

1. partir du probleme simple
2. montrer que le vrai sujet est architectural
3. montrer les modes d'execution
4. montrer les artefacts
5. montrer la comparaison local vs provider
6. conclure sur supervision humaine et fallback
